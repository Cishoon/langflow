# Langflow Product Overview

Langflow is a visual platform for building and deploying AI-powered agents and workflows. It enables developers to create LLM applications through both a drag-and-drop visual interface and Python code.

## Core Capabilities

- Visual flow builder for creating AI workflows
- Multi-agent orchestration with conversation management
- Support for all major LLMs (OpenAI, Anthropic, Google, etc.)
- Vector database integrations (Chroma, Pinecone, Qdrant, etc.)
- Deploy workflows as REST APIs or MCP servers
- Export flows as JSON for Python applications
- Observability integrations (LangSmith, LangFuse, LangWatch)

## Key Concepts

- **Flows**: Visual workflows connecting components (nodes) via edges
- **Components**: Reusable building blocks (models, tools, data sources, agents)
- **Playground**: Interactive testing environment for flows
- **Projects**: Organizational containers for flows

## Target Users

- Developers building LLM-powered applications
- Teams prototyping AI agents and workflows
- Organizations deploying production AI systems
